# মসজিদ ও সমাজ ব্যবস্থাপনা - ইনফিনিটিফ্রি (InfinityFree) হোস্টিং গাইড

এই ফোল্ডারে (`/public/web-export/`) আপনার মসজিদ ও সমাজ ব্যবস্থাপনা সফটওয়্যারের একটি সম্পূর্ণ PHP & MySQL ওয়েব সংস্করণ প্রস্তুত করা হয়েছে, যা যেকোনো ফ্রি বা পেইড হোস্টিং যেমন **InfinityFree**, **000webhost** কিংবা যেকোনো লোকাল সার্ভারে (XAMPP/WAMP) খুব সহজেই হোস্ট করা যাবে।

---

### ইনফিনিটিফ্রি (InfinityFree) এ হোস্ট করার ধাপসমূহ:

১. **অ্যাকাউন্ট তৈরি ও হোস্টিং:**
   - [InfinityFree.net](https://infinityfree.net) এ গিয়ে একটি ফ্রি অ্যাকাউন্ট তৈরি করুন এবং একটি ফ্রি সাবডোমেইন (যেমন: `yourmasjid.epizy.com` বা `42web.io`) ক্রিয়েট করুন।

২. **ডাটাবেজ তৈরি (MySQL Database):**
   - cPanel বা VistaPanel এ প্রবেশ করে **MySQL Databases** এ যান।
   - একটি নতুন ডাটাবেজ তৈরি করুন (যেমন: `masjid_db`)।
   - ডাটাবেজ হোস্ট নেম (যেমন `sql100.infinityfree.com`), ডাটাবেজ ইউজারনেম, পাসওয়ার্ড এবং ডাটাবেজ নাম নোট করুন।

৩. **ডাটাবেজ স্কিমা আপলোড (phpMyAdmin):**
   - cPanel থেকে **phpMyAdmin** এ প্রবেশ করুন এবং আপনার তৈরি করা ডাটাবেজটি সিলেক্ট করুন।
   - **Import** ট্যাবে গিয়ে এই ফোল্ডারের `schema.sql` ফাইলটি আপলোড করে **Go** প্রেস করুন। এতে সমস্ত প্রয়োজনীয় টেবিল ও ডেমো ডেটা তৈরি হয়ে যাবে।

৪. **কানেকশন কনফিগারেশন (`db.php`):**
   - আপনার কম্পিউটারে `db.php` ফাইলটি নোটপ্যাড বা কোড এডিটরে ওপেন করুন এবং নিচের তথ্যগুলো আপনার ইনফিনিটিফ্রি ডাটাবেজ তথ্য দিয়ে আপডেট করুন:
     ```php
     define('DB_HOST', 'আপনার_ডাটাবেজ_হোস্ট_এখানে_দিন'); // যেমন: sql100.infinityfree.com
     define('DB_USER', 'আপনার_ইউজারনেম_এখানে_দিন'); // যেমন: if0_38xxxxxx
     define('DB_PASS', 'আপনার_পাসওয়ার্ড_এখানে_দিন'); // cPanel পাসওয়ার্ড
     define('DB_NAME', 'আপনার_ডাটাবেজ_নাম_এখানে_দিন'); // যেমন: if0_38xxxxxx_masjid_db
     ```

৫. **ফাইল আপলোড (File Manager):**
   - cPanel এর **Online File Manager** এ প্রবেশ করুন এবং আপনার ডোমেইনের `htdocs` ফোল্ডারের ভেতরে প্রবেশ করুন।
   - এই ফোল্ডারের সব ফাইল (`index.php`, `db.php`, `schema.sql`, `README.md`) `htdocs` ফোল্ডারে আপলোড করুন।

৬. **অ্যাপ্লিকেশন ব্যবহার:**
   - এবার ব্রাউজারে আপনার ডোমেইন ভিজিট করলেই আপনার মসজিদ ও সমাজ ব্যবস্থাপনা ওয়েব অ্যাপটি লাইভ দেখতে পাবেন! এখানে আপনি মাসিক চাঁদা আদায়ের খাতা (মাসিক ও বছরভিত্তিক কোন সদস্য কত দিল বা বকেয়া আছে), পরিবার তালিকা, নতুন পেমেন্ট এন্ট্রি ইত্যাদি সব ফিচার সুন্দরভাবে ব্যবহার করতে পারবেন।
